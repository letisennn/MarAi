# E1 — results (DRY RUN on synthetic data)

> **These are not research findings.** The pipeline currently runs on the
> synthetic price source (`marc.ingestion.synthetic_source`), which builds
> deterministic pseudo-random paths with a built-in upward drift and occasional
> "attention bursts". Any structure the stats layer reports here is partly
> circular — we put it in. This document exists to show the machinery produces
> the right *shape* of output and to lock the reporting format. The real E1 runs
> once a real, survivorship-aware price source is loaded (see
> `docs/data_sources.md`).

Generated by `marc pipeline --source synthetic` → `experiment_result` (experiment
`E1`). Re-run `uv run marc stats` to refresh; browse in the app's **Experiments**
page.

## Setup actually used

| | |
|---|---|
| Universe | `nordic_smallcap_v1`, 52 seed names (11 delisted/acquired/bankrupt) |
| Observations | ~10.7k weekly (Fri close), 2020-01-31 → 2026-06-26 |
| Segment filter (headline) | `cap_segment_at_entry = 'small'` (~5.7k obs); `mid` (~2.2k) reported for context only |

| Base price P0 | trailing 5-day mean adjusted close |
| Turnover gate | day counts only if turnover ≥ max(SEK 250k, 0.5 × 60d median) |

## E1b — univariate (discovery)

- **Weekly rank IC:** the momentum family (`ret_3m`, `ret_6m`, `ret_12m`,
  `dist_52w_high`) shows mean weekly IC ≈ 0.20–0.23 vs `fwd_ret_60` / `fwd_ret_90`,
  with block-bootstrap CIs excluding zero. **This is circular** — the synthetic
  paths have drift + momentum-ish bursts by construction.
- Volume / volatility features (`rvol_*`, `vol_expansion`, `amihud_20d`) show IC
  near zero — also expected, the generator adds volume noise with little
  forward information.
- Quintile sorts and top-quintile event lift are stored for every
  feature × horizon (including the null ones).

## E1c — Fama-MacBeth (discovery)

257 weekly cross-sectional regressions of `fwd_ret_20` on standardised features.
Averaged coefficients load positive on the momentum features, ~zero elsewhere.
Simple t-stats only; Newey-West SEs are a TODO.

synthetic data. All matches + outcomes are in `signal_log` / `signal_outcome`.
