# Experiment E1 — Pre-registration (DRAFT, not yet locked)

> any analysis. No post-hoc changes to the grid below.
> Parameter values live in `config/universe.yml` and `config/targets.yml`;
> this document is the narrative + the locked analysis grid.

## Question

Does simple price/volume behaviour carry information about forward returns and
large-move events in Nordic small-caps?

## Hypothesis

H1: At least one of the pre-registered price/volume features has a monotonic
relationship with forward returns and a materially higher `P(large move | signal)`
than the base rate, that survives BH-FDR and holds on the 2025–2026 holdout.

Null: no feature clears FDR, or effects do not replicate out-of-sample.
(A confirmed null is a valid, internally-published result.)

## Universe

`nordic_smallcap_v1` per `config/universe.yml`, point-in-time membership.

- **Admission:** point-in-time market cap SEK 50m – 1.7bn (~EUR 150m, Nasdaq
  Small Cap ceiling) + 60d median turnover ≥ SEK 250k + last close ≥ SEK 1.
  First North, Spotlight and NGM included; no venue excluded in advance.
- **Cap segment:** every observation is tagged `cap_segment_at_entry` ∈
  {small, mid} from its point-in-time market cap (`small` ≤ SEK 1.7bn).
- **Retention after growth:** a name admitted as `small` that later grows past
  the ceiling stays in the panel; its later observations are tagged `mid`.
- **Main analysis filters to `cap_segment_at_entry = 'small'`.** `mid`
  observations are kept only for a separate "growing out of small-cap" study and
  are excluded from E1a–E1d headline results.
- Known limitation: free data omits delisted tickers → universe incomplete;
  recorded, not hidden.

## Observations

Weekly, Friday close, 2020-01-03 → 2026-06-26. A `(security, date)` is an
observation iff `in_universe` as-of date and ≥ 252 prior trading days.
Discovery period: 2020-01 → 2024-12. Holdout: 2025-01 → 2026-06 (untouched
until the single final evaluation).

## Features (v0.1, locked list — ~18)

Trailing return 1w / 1m / 3m / 6m / 12m · distance to 52-week high · 20-day-high
breakout flag · gap frequency (20d) · relative volume 5/60 · relative volume
20/200 · volume trend (60d slope) · volume acceleration · realized vol 20d ·
realized vol 60d · vol-expansion ratio (20d/60d) · Amihud illiquidity (20d) ·
log market cap · price-level bucket.

All computed causally from data with `event_time <= t`.

## Targets (locked — `config/targets.yml`, target_set_version v0.1)

**Base price P0** — denominator for every forward metric — is the trailing
**5-trading-day mean of the adjusted close** over sessions `[t-4, t]`, not a
single `close(t)`. This stops one anomalously low print at `t` from making a
threshold artificially easy to reach. The 10-day mean is computed and reported
as a robustness check, not as the headline.

**Turnover gate** — a day `d` contributes to an event / max-return / drawdown /
time-to-peak only if its SEK turnover ≥ `max(SEK 250k, 0.5 × trailing 60-day
median daily turnover)`. Single thin trades that print an extreme high or low
are ignored.

- **Forward point return** `fwd_ret_h = adjusted_close(t+h) / P0 − 1`,
  h ∈ {5, 20, 30, 60, 90, 180} trading days. `fwd_ret_h_sm` (5-day mean
  endpoint) reported as robustness.
- **Events** (gated intraday-high based):
  `event = 1` iff `max{ adjusted_high(d) : d ∈ (t, t+H], gate(d) passes } ≥ threshold × P0`
  for `up_10_5d`, `up_25_20d`, `up_50_30d`, `up_50_60d`, `up_50_90d`,
  `up_100_180d`.
- **Path metrics** (gated): `fwd_max_ret_h`, `fwd_max_dd_h`, `days_to_peak_h`,
  `sustained_h` (= `fwd_ret_h ≥ 0.5 · fwd_max_ret_h`).
- **Delisting inside a window** (`config/targets.yml`, `docs/methodology.md`
  §2.3): bankruptcy/liquidation → terminal −100% at delisting date, path ends;
  acquisition/merger → final price = the offer/cash price (not last traded);
  suspension → carry last price, no new gated highs/lows.

## Analyses

- **E1a** base rates: unconditional event rate per {year, country, cap segment}
  and pooled — reported for `small` and `mid` separately; `mid` is context only.
- **E1b** univariate: weekly cross-sectional quintile sort per feature → pooled
  forward return + event rate per quintile, Q5−Q1 spread; weekly Spearman IC →
  mean IC + Newey-West t; block bootstrap (≈26-week blocks) CIs.
- **E1c** multivariate: Fama-MacBeth weekly OLS of `fwd_ret_h` on standardised
  features; average coefficients, Newey-West t.
- **E1d** composite rules (pre-registered, max 3):
  1. `relvol_5_60 ≥ 3` ∧ `ret_1m > 0.20` ∧ `vol_expansion ≥ 1.5`
  2. `breakout_20d = 1` ∧ `relvol_20_200 ≥ 2`
  3. `dist_52w_high ≥ -0.05` ∧ `ret_3m > 0` ∧ `volume_accel > 0`
  Evaluate `P(event|rule)` vs base on the discovery period; then **one** locked
  run on the holdout. Report precision, recall, lift, n.

All E1a–E1d headline results are computed on `cap_segment_at_entry = 'small'`
observations only.

## Multiple-testing control

Family = features × horizons × {IC, quintile-spread} for E1b, plus the 3 rules ×
6 events for E1d. Report family size. BH-FDR at q = 0.10. Holdout evaluated once.
